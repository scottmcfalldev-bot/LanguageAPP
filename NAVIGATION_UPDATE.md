## Reading Practice Page

Click **📖 Reading Practice** in the sidebar to access the gloss reader anytime!

### Language Selection Screen

When you first visit Reading Practice, you'll see:

```
Reading Practice
Character-by-character breakdown with visual mapping to English

Choose a language:

┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│     🇪🇸      │  │     🇯🇵      │  │     🇨🇳      │
│             │  │             │  │             │
│   Spanish   │  │  Japanese   │  │  Mandarin   │
│             │  │             │  │             │
│ 4 examples  │  │ 4 examples  │  │ 5 examples  │
└─────────────┘  └─────────────┘  └─────────────┘

What you'll learn:
• See how each language constructs meaning differently
• Understand character/word-by-character breakdowns
• Compare literal vs. natural English translations
• Learn grammar patterns through visual mapping
```

### Reading Session

After selecting a language, you'll see the interlinear gloss reader:

```
Spanish Reading Practice                1 / 4

┌───────────────────────────────────────────┐
│              Me gusta el café             │
└───────────────────────────────────────────┘

                [Show Breakdown]

┌─────────┬─────────┬─────────┬─────────┐
│   Me    │  gusta  │   el    │  café   │
│   meh   │ GOOS-tah│   el    │ kah-FEH │
│  to-me  │it-pleases│ the (m) │ coffee  │
└─────────┴─────────┴─────────┴─────────┘

Literal: "to-me it-pleases the coffee"
Natural: "I like coffee"

💡 Spanish says "coffee pleases me" instead of "I like coffee"!

     [← Previous]              [Next →]
```

## Updated Session Flow

**Before:**
1. SRS Cards (5 min)
2. Gloss Reader (5 min) ← Part of session
3. Conversation (10 min)
4. Writing (10 min)

**Now:**
1. SRS Cards (5 min)
2. Conversation (15 min)
3. Writing (10 min)

**Reading Practice = Standalone Feature**
- Access anytime via sidebar
- Not part of daily session
- Practice at your own pace
- Choose any language

---

## Why This Is Better

**Before:**
- Gloss reader only during daily session
- Forced language based on schedule
- Fixed order

**Now:**
- Practice reading anytime you want
- Choose any language on demand
- Independent of daily schedule
- More flexible learning

---

## Use Cases

### 1. Daily Session Focus
Complete your daily session (SRS + Conversation + Writing) without distractions.

### 2. Extra Practice
Finished your session but want to keep learning? Jump into Reading Practice!

### 3. Specific Language Study
Want to deep-dive into Japanese grammar? Go directly to Reading Practice → Japanese.

### 4. Weekend Learning
Not doing a full session? Just practice reading on weekends!
